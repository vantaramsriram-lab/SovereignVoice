# Public sample analyses

This folder is intentionally empty in the initial pull request.

To add a public sample:
1. Run an analysis using audio you recorded yourself or have permission to publish.
2. On the Demo page, use **Export** on that analysis.
3. Copy the downloaded JSON file into this folder.
4. Commit the JSON file to the repository.

Each JSON file contains the original input audio, generated response audio, transcript, and analysis results. These files are bundled into the public website and can be accessed by every visitor. Keep recordings short (about 30–60 seconds), and never add real customer calls, personal data, or confidential information.

The Sample analyses section appears automatically when at least one JSON file is present. Samples are read-only in the website; visitors cannot delete them. Their own analyses remain in their own browser storage.
